# سامانهٔ حضور و غیاب با تشخیص چهره

## امکانات

- **داشبورد** — کارت‌های آماری (کل کارمندان، حاضر امروز، تأخیر، غایب) و جدول آخرین ترددها
- **کارمندان** — افزودن، ویرایش و حذف کارمند
- **ثبت چهره** — گرفتن تا ۵ نمونه از چهرهٔ هر کارمند با وب‌کم
- **کیوسک حضور و غیاب** — تشخیص زندهٔ چهره و ثبت ورود/خروج
- **گزارش‌ها** — محاسبهٔ روزهای کاری، حاضر، غایب، تأخیر و اضافه‌کاری، تأیید/رد، خروجی اکسل و مدیریت مرخصی‌ها
- **تنظیمات** — ساعت شروع کار، ساعت کاری استاندارد، آستانهٔ تشخیص، پشتیبان‌گیری/بازگردانی و دادهٔ نمونه

## پشتهٔ فنی

| لایه | فناوری |
|---|---|
| بک‌اند | Python + Flask |
| تشخیص محل چهره | OpenCV YuNet |
| تشخیص هویت | OpenCV SFace — بردار ویژگی ۱۲۸‌بُعدی |
| ذخیره‌سازی | فایل‌های JSON در پوشهٔ `data/` (بدون نیاز به دیتابیس) |
| تاریخ شمسی | `jdatetime` |
| خروجی اکسل | `openpyxl` |

## راه‌اندازی

**پیش‌نیاز:** پایتون ۳٫۹ به بالا

<div dir="ltr">

```bash
# ۱) نصب وابستگی‌ها
pip install -r requirements.txt

# ۲) دانلود مدل‌های تشخیص چهره (یک‌بار)
python download_models.py

# ۳) اجرا
python app.py
```

</div>

سپس در مرورگر باز کنید: `http://127.0.0.1:5000`

اگر دانلود خودکار ناموفق بود، دو فایل زیر را دستی در پوشهٔ `models/` بگذارید — هر دو در مخزن [OpenCV Zoo](https://github.com/opencv/opencv_zoo) در دسترس‌اند:

- `face_detection_yunet_2023mar.onnx`
- `face_recognition_sface_2021dec.onnx`

> **نکتهٔ وب‌کم:** مرورگرها دسترسی به دوربین را فقط روی `localhost` یا `https` می‌دهند. اجرای محلی با همین آدرس بالا مشکلی ندارد. برای دسترسی از دستگاه دیگر، برنامه را پشت `https` قرار دهید.

## نحوهٔ استفاده

۱. در **کارمندان**، افراد را اضافه کنید.
۲. در **ثبت چهره**، کارمند را انتخاب و چند نمونه از چهره‌اش را ثبت کنید.
۳. در **کیوسک**، دوربین را روشن کنید؛ پس از شناسایی، دکمهٔ **ورود** یا **خروج** را بزنید.
۴. در **گزارش‌ها** بازهٔ تاریخ را انتخاب و خروجی اکسل بگیرید.

برای دیدن سریع گزارش‌ها بدون ثبت دستی، از **تنظیمات ← دادهٔ نمونه** استفاده کنید. کارمندان نمونه چهرهٔ ثبت‌شده ندارند و فقط برای پر شدن گزارش‌ها هستند.

## ساختار پروژه

<div dir="ltr">

```
attendance-system/
├── app.py              # برنامهٔ Flask و مسیرها (صفحه‌ها + API)
├── face_engine.py      # موتور پردازش تصویر و تشخیص چهره (OpenCV)
├── reports.py          # محاسبهٔ گزارش‌های حضور و غیاب
├── storage.py          # ذخیره‌سازی JSON و توابع تاریخ شمسی
├── download_models.py  # دانلود مدل‌های ONNX
├── requirements.txt
├── templates/          # قالب‌های HTML (Jinja2)
├── static/             # CSS و JavaScript سمت کلاینت
├── models/             # فایل‌های مدل ONNX (پس از دانلود)
└── data/               # فایل‌های دادهٔ JSON (هنگام اجرا ساخته می‌شوند)
```

</div>

## حریم خصوصی

نمونه‌های چهره به‌صورت بردار عددی ۱۲۸‌بُعدی ذخیره می‌شوند، نه تصویر، و هرگز از دستگاهی که برنامه روی آن اجرا می‌شود خارج نمی‌شوند. تمام داده‌ها در فایل‌های JSON محلی در پوشهٔ `data/` قرار دارند.
